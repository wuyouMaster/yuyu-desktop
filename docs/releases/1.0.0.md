# YUYU 1.0.0

桌面应用正式版，支持 macOS arm64（Apple Silicon）。微信、钉钉和 Telegram 的独立运行时仍为实验性开发预览，按需下载；桌面版本号不表示这些运行时已达到稳定状态。

## 下载与更新

- macOS arm64 提供 DMG 和 ZIP；本次不提供 Windows 或 Intel Mac 正式安装包。
- 本版本未获 Apple Developer ID 签名或公证，macOS Gatekeeper 可能阻止首次打开。
- macOS 更新检查会引导前往 Release 页面下载，暂不提供应用内自动安装更新。
- Windows 用户继续使用已有 Windows 开发预览。旧 Windows 预览的更新检查可能因本正式版没有 `latest.yml` 而失败，可从此前预览的 Release 页面下载原有安装包。

## 实验性运行时

| 数据源 | 固定版本 | 当前边界 |
| --- | --- | --- |
| 微信 | `0.1.0-dev.13` | macOS arm64 开发预览；能力取决于客户端版本、运行时检查和用户授权，安装成功不等于连接或发送验收通过。 |
| 钉钉 | `0.1.0-dev.2` | macOS arm64 开发预览；钉钉 9.0.5 / build 59563623 做过有限只读查询，不能据此推断发送模块兼容。 |
| Telegram | `0.1.0-dev.5` | macOS arm64 开发预览；分别提供 Telegram Desktop 和 macOS 原生 Telegram 入口。 |

原生 Telegram 只对 13.2.0 / build 283467 完成有限真实只读检查，可浏览本地会话、消息分页和已识别的附件元数据。附件播放、下载、发送、昵称解析、完整云端历史及其他客户端构建尚未验收。已安装 Telegram dev.3 的用户需更新运行时并重启应用。

三个运行时继续保留 `development-only` 标记及原有版本、下载地址与摘要校验。它们当前没有 Windows 发行包。不要将桌面正式发布视为全部数据源、真实账号或消息发送能力已经完成验收。

## 已知限制

全新安装默认关闭本地 API，需要时可手动开启；已有设置保留。远程模板市场暂不可用，内置和本地模板仍可使用。

真实安装升级、其他客户端兼容性和完整第三方许可审核仍需后续验收。本仓库保留原作者和第三方依赖署名，相关说明见 [NOTICE](https://github.com/wuyouMaster/yuyu-desktop/blob/v1.0.0/NOTICE.md)。
