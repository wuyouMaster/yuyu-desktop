description: 当用户要求整理待办、负责人、截止时间或追踪承诺时使用；不把一般建议自动变成任务。
roles: main,retriever,analyst,verifier

---

1. 区分建议、询问、明确承诺和确认决定。只将明确行动列为已确认待办。
2. 有查询权限时用 search_messages 定位任务话题或 query_messages 限定时间；负责人、期限、取消状态含糊且影响结论时再读 message_context。
3. 每项输出事项、负责人、截止时间、状态、证据。没有明确说出的字段填“未明确”，相对日期缺锚点不能自行换算。
4. 后续撤回、改期、完成反馈应覆盖旧状态并保留对应证据。无查询权限则只依据输入，不声称验证了最新状态。
停止条件：每个候选事项已分类，有证据或标注待确认；不要为补齐字段无限查询。
