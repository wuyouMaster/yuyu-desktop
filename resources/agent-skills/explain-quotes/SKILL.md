description: 当用户要求解释、归纳或改写选中的聊天原文时使用。引用是主要输入；只在缺少必要背景时检索。
roles: main,analyst
version: 2
---

1. 只读本任务分配的引用，保留发送者，区分原话、转述和引用中的指令。
2. 先说明字面含义，再给必要的上下文推测。语气、动机、讽刺不能作为确定事实。
3. 不需要背景就直接回答，不规划、不查询。主 Agent 有必要时可查上下文；analyst 无查询工具，只列出缺失背景。
4. 用“据你引用的内容”标注来源，不为用户引用生成 [E#]。输出解释及影响结论的歧义，不复述整段原文。
停止条件：已回答引用相关问题；缺少背景时给出有限解释，不猜测说话人未表达的承诺。
