# Attribution and delivery boundary

Application code was migrated from the user's wechat_decrypt application checkout. Existing author
metadata (`Qingmao`) is preserved; migration does not establish ownership of every upstream component
or grant a new source license. Dependencies retain their own package licenses and attribution.

The separately downloaded wechat_chatter compatibility route retains its GPL-3.0 upstream and
modification notices in the runtime. No upstream script, offsets, native patch implementation or
private research registry is distributed in this application repository. Runtime release artifacts
have their own source/notice requirements and must be reviewed independently before publication.

Generated app icons derive from the reviewed SVG source. Visual baseline images, binaries, models,
source archives, logs and test outputs are external or generated inputs and are not repository files.
